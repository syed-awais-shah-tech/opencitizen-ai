# OpenCitizen AI - Data Pipeline

This directory contains ingestion, chunking, embedding, and dataset cleaning modules for OpenCitizen AI.

## Planned Modules (Milestones 1–2)

- `ingestion/`: Document parsers for PDF text extraction with page preservation.
- `chunking/`: Semantic and recursive text chunking strategies.
- `embeddings/`: Vector embedding generation via the `AIProvider` (Gemini API).
- `tabular/`: Tabular dataset normalization and DuckDB table loader.
